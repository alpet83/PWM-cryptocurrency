## 4. Safety

- Снятие серверной проверки домена для burn **меняет trust boundary**: burn остаётся односторонним по marks отправителя; бенефициар — метаданные. Риски «подставного» получателя снимаются тем, что учёт marks на другом шарде этим телом не двигается без отдельной семантики — согласуется с заявленной моделью V2-7. Регресс по 409 покрыт HTTP-тестом.
- `Chain::seal` больше не крутит accrual marks — экономика marks теперь зависит от genesis seed + прочих путей в `State` (claim/stake maturity и т.д.); это намеренное изменение; тесты фиксируют отсутствие начисления при seal.
