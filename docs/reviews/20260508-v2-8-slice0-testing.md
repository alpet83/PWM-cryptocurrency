- В RFC 15 **§11** перечислены только **Slices 1–5** (wire, negotiation, live sync, catch-up, hardening). Отдельных буллетов **«Slice 0 — RFC freeze»** нет.
- Приёмка Slice 0 фактически выражена через **статус документа** (`Frozen (Sprint V2-8 Slice 0)`), **Abstract** и нормативные разделы 5–10. **Тестируемо** в смысле **docs-gate / чеклист ревью** (наличие секций, freeze, перекрёстные ссылки, отсутствие противоречий с RFC 8).
