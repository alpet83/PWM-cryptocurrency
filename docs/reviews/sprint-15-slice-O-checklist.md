## Проверки после каждого merge

- `cargo fmt`, `cargo test -p <crate>` для изменённых crate; при касании общего протокола — `cargo test --workspace` по времени CI.
- При пакетной декомпозиции `pwmd` `transport` (серия волн O.1) между волнами — те же автоматические проверки; **эксплуатационная** приёмка рефакторинга — по закрытию слайса (решение владельца).
- При изменении TUI — быстрый smoke: запуск `pwm-tui`, F6 cross-shard не регрессирует (или пометить в отчёте).
