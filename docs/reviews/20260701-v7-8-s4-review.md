## 9. Nits (non-blocking)

1. **NIT-1:** Dedupe or hide `session_send` `op_history` rows when matching journal `send`/`burn` exists (same nonce + amount window).
2. **NIT-2:** `confirm_journal_nonces`: skip account when `row.nonce == UNKNOWN_INIT_NONCE_SENTINEL`.
3. **NIT-3:** `read_journal` — on line read error, skip line and continue instead of `map_while(Result::ok)` truncating tail.
4. **NIT-4:** Reload `journal_cache` on overlay reopen or add refresh hint if journal grew while overlay was open.
