# Snapshot Hex Refactor Design Review (Slice 21)

## Контекст
- Цель: снизить избыточность `pwm-data.json`, заменив byte-array представление на hex-строки.
- Область: только snapshot wire-формат (`pwmd`), без изменения консенсусной семантики.

## Предлагаемый контракт
- Новый формат: `version: 2`.
- Все бинарные поля фиксированной длины (`[u8;32]`, `[u8;64]`) хранить как lowercase hex без `0x`:
  - 32 байта -> 64 символа;
  - 64 байта -> 128 символов.
- Большие финансовые значения (`u128`) хранить как decimal string.
- `u64/u32/u16` оставить JSON-числами.
- Имена полей по возможности сохранить, чтобы минимизировать diff и риск миграции.

## Валидация
- Hex: только `[0-9a-f]`, строго фиксированная длина.
- Decimal string: только цифры, диапазон `u128`, без пробелов/`+`.
- Сохраняются текущие инварианты:
  - уникальность account id;
  - корректность ссылок (`marks_quota`);
  - консистентность роуминга через восстановление пула;
  - replay-check цепочки (`state_root`/`tx_root`/`prev_hash`) без послаблений.

## Стратегия миграции
- Pre-public: допустим controlled break, но рекомендовано короткое dual-read окно.
- Запись: сразу только `v2`.
- Чтение: временно поддержать `v0/v1/v2`, затем убрать `v0` (и далее `v1`) по плану.
- Автообновление: при загрузке `v0/v1` и следующем autosnapshot сохранять `v2`.

## План внедрения
1. Добавить `SnapshotDataV2` и связанные wire-типы.
2. Реализовать конвертеры `core <-> v2 wire` в `save_snapshot/load_snapshot`.
3. Добавить strict parser helpers для hex/dec.
4. Расширить тесты:
   - roundtrip `v2`;
   - negative-cases (битый hex/dec);
   - миграция `v0/v1 -> v2`;
   - smoke: boot -> seal -> autosnapshot -> restart.
5. Зафиксировать policy: uppercase hex отклоняется, canonical writer всегда lowercase.

## Риски и mitigation
- Риск неполного покрытия вложенных binary полей в `blocks/tx`.
  - Mitigation: отдельные v2 wire-структуры + negative тесты глубокой вложенности.
- Риск неявной несовместимости.
  - Mitigation: dual-read окно + явные логи миграции.

## Вердикт
`approve with nits`:
- Дизайн реализуем, упрощает snapshot и уменьшает объём.
- Нюанс: до кода нужно финально зафиксировать политику leading zeros для decimal strings.
