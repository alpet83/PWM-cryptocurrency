# MVP v5.0.0 — Tokenomics hardening (implementation-complete devnet)

**Release date:** 2026-06-02  
**Tag:** `v5.0.0`  
**Status:** Owner sign-off complete. PoA lab devnet — not a production mainnet launch.

---

## Highlights

### Tokenomics (V5 core)

- **Lazy marks** from staked PWM only: `marks_last_block` cursor, `effective_marks` at poll/touch, saturation toward `u32::MAX`.
- **Float inflation** in seal: dynamic `block_reward` via `season_coeff_ppm` (~5% annual target).
- **`ClaimTx` retired**; IPv4 allocation via on-chain **`ClaimIPv4Batch`** (registry-gated).
- **Deferred policy activation:** `ActivationMode::Deferred { activate_at_height }` with CLI `tx-policy-set --activation deferred`.

### Snapshot & trust

- **Snapshot schema v3** with additive account fields.
- **Genesis anchor light** ([ADR 0008](docs/adr/0008-snapshot-genesis-anchor-light.md)) — light binding of snapshot trust to genesis state.

### Operator UX

- **pwm-tui:** effective marks in detail pane, saturation column, V5 F5 burn path (stake → wait → burn materialized marks).
- **pwm-cli:** `account-info` with marks detail; deferred policy CLI.
- Runbook: [v5-tui-marks-operator-path](docs/runbooks/v5-tui-marks-operator-path.md).

### Pre-publish polish (2026-06-02)

- TUI operator UX, `mk_acct_row` test DRY, naming sweep (0 violations), legacy `marks_quota` removed from pwmd snapshot.
- Integrated review: [prepublish-polish](docs/reviews/20260602-v5-prepublish-polish-integrated-review.md).

### Baseline (V4, unchanged milestone)

- Policy runtime: `PolicyTx`, `evaluate_policy`, hybrid `INIT` (`init_v4`), structured `E_POLICY_*` rejects.
