# Оффчейн batch-burn (заглушка v0)

Назначение: прототип агрегированного сжигания без SMTP/HTTP продакшена.

1. Провайдер собирает список записей `{ user_id, mark_amount, nonce }`.
2. Строится Merkle root (BLAKE3 leaf + бинарное дерево как в `pwm_core::offchain`).
3. Провайдер подписывает Ed25519 сообщение `PWMv0-OFFCHAIN-BATCH || LE_U64(batch_id) || merkle_root`.
4. Клиент может проверить включение листа в дерево и подпись.

Ончейн-мост в v0 **не** требуется; API ноды может экспортировать только превью/верификацию через CLI `pwm offchain-verify`.
