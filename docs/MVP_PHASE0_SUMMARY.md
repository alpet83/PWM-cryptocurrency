# MVP Phase 0: что уже готово

Этот документ описывает результат нулевой фазы простыми словами, без внутренней технической детализации.

## Коротко

В фазе 0 собран рабочий прототип сети PWM для dev/test-сценариев:

- есть локальная нода с API;
- есть базовые переводы и операции через CLI;
- есть TUI-прототип для просмотра состояния;
- есть автотесты и ручной smoke-прогон.

## Важно уточнить (по вашим формулировкам)

Вы близко описали картину, но есть важные уточнения:

- Это не "чисто оффчейн система".  
  Основной контур уже on-chain в рамках devnet: нода держит состояние, принимает транзакции и формирует блоки.
- Оффчейн-часть сейчас есть только как отдельная заглушка (batch/Merkle demo), а не как основной режим работы всей системы.
- "Кошельков в привычном виде" действительно пока нет.  
  Есть developer-CLI (ключи, derive, отправка tx), но нет пользовательского wallet UX уровня массовых продуктов.
- P2P между нодами/валидаторами в пользовательском смысле пока нет.  
  В фазе 0 фокус на локальном devnet-сценарии, а не на полноценной одноранговой сети.

## Что пользователь уже может сделать

1. Поднять локальную ноду `pwmd`.
2. Сгенерировать ключи и отправить базовые транзакции через `pwm-cli`.
3. Открыть `pwm-tui` и видеть состояние аккаунтов/сети.
4. Проверить базовые сценарии по готовым tester-гайдам.

## Что достигнуто к концу фазы 0

- **Базовый runtime работает:** API ноды, mempool, сборка блоков, снапшоты состояния.
- **CLI покрывает основной минимум:** `key-gen`, derivation, `tx-init`, `tx-send`, `tx-stake`, `tx-unstake`, `tx-burn-mark`.
- **TUI уже полезен как прототип:** есть панели, фокус, навигация, реакция на клавиши, debug-режим.
- **Качество подтверждено прогонами:** unit/smoke тесты и ручной прогон devnet-сценариев.

## Ограничения фазы 0

- Нет production-ready wallet UX.
- Нет полноценной P2P-сети и сетевой координации независимых нод.
- TUI остаётся ограниченным для production-сценариев; при этом в Phase 1 уже реализован рабочий F6 send-flow, а ручной операторский smoke ещё требуется.
- Оффчейн batch не интегрирован как полноценный bridge/продуктовый поток.

## Что это значит для следующего этапа

Фаза 0 закрывает технический "каркас": система уже запускается, принимает базовые действия и наблюдается через TUI/CLI.  
Следующий шаг — переход от dev-прототипа к более пользовательскому режиму: удобный wallet UX, более зрелая сетевая модель и доработка TUI до полноценных сценариев действий.
