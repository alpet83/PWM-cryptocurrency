# MVP v6.0.0 — Consensus evolution + address security runtime

**Release date:** 2026-06-17  
**Tags:** `v6.0.0` · `MVP-V6-RC`  
**Status:** Owner sign-off complete (2026-06-17). PoA incremental-PoS lab devnet — not a production mainnet launch.

---

## Highlights

### Consensus (V6 core)

- **Stake-gated validator admission** on epoch boundaries (`min_validator_stake`, `active_validator_indices`).
- **RFC16 multi-proposer rotation** + primary-miss failover (≤ 1 skipped block).
- **Snapshot schema v4** with trust-load fastpath for operator restarts.
- **Slashing evidence stubs** (append-only, no seizure) + **peer sync scoring**.

### Cross-shard & security

- **Mode B escrow:** EXPORT balance lock, timeout refund, IMPORT release.
- **Address flags runtime** ([ADR 0009](docs/adr/0009-address-flags-runtime-enforcement.md)): `COSIGN_NON_DISABLEABLE`, `CONSERVATION` delayed outgoing transfers.
- **Emergency routing** ([ADR 0011](docs/adr/0011-policy-activation-target.md)): `ActivatePolicy` + `activation_target`, fee-free activation, balance evacuation to rescue; prepared activation from `pwm tx-init`.
- **Stake evacuation on emergency** deferred to V7 ([ADR 0012](docs/adr/0012-emergency-stake-evacuation.md)).

### Operator UX (RC batch)

- **pwm-cli:** wallet v3 `--index` on tx commands; `addr-bruteforce --rpc offline`; graceful no-match errors.
- **Windows builds:** `pwmd`, `pwm`, `pwm-tui` embed **PWM MVP v6** PE metadata and shared icon (`assets/branding/pwm.ico`).
- **pwmd:** lease self-takeover after restart; init-phase snapshot load observability.
